# 嘉利采购 Fact Book

静态采购分析网页，可在新版 Chrome 或 Edge 中离线打开 index.html。样式、脚本、数据及参考图片均内嵌；外部资料链接需要联网。

## 板块与期间

1. **PO采购树状图**：12大类、28小类。展示含税金额、SKU及供应商数；小类占比以所属大类为分母。点击小类查看供应商金额、SKU、累计占比与CR10分界，并可继续进入采购明细。
2. **小类 Fact Book**：金额、SKU、CR50、供应商CR10、产品组、完整物料及长尾供应商均采用PO数据。研究说明与适用参考图片沿用，并核对新增物料的产品形态；未知用途保留待核对。完整期间193个产品组，2026年1—8月189个产品组。
3. **采购协同**：统一比较2026/01—2026/08，嘉利采用PO采购，得邦采用入库数据。21家共同供应商，其中3家较原清单新增；嘉利含税PO金额143,887,456元、得邦含税入库金额21,207,563元。保留108组相同／相似物料，105组可比较，M0135、M0207、M0208本期缺少一方记录。页首、表头、曲线及明细标明期间与数据口径；均价直接用含税总金额除以数量，负数按原值净计。协同潜力总览覆盖PO的28个小类。
4. **入库 spend cube**：保留2026年1—9月原数据，725家供应商、20,743个SKU、77个已识别品牌，含税入库金额1,521,281,699元。
5. **PO spend cube**：品类、供应商、品牌三个维度，支持小类筛选、供应商份额、品牌简介与来源、原始PO明细及CSV下载；可下载独立HTML。
6. **专有名词检索**：保留采购、报价及工艺术语解释。
7. **资料来源**：原文链接、摘要、支持内容及适用边界。

po-spend-cube.html是独立、可离线使用的PO报告，已移除用户指定的底部说明。完整Fact Book的05板块采用同一份数据，离线无需依赖另一文件。

产品参考图和形态示意不代表嘉利准确料号实物；具体材料、接口、性能与可替代性需按图纸和供应商交付核对。报价拆解用于询价，不代表嘉利实际成本；无直接来源的成本占比不列示。未能核实的品牌保持未识别，不以供应商名称或通用型号猜认。

## Spend Cube 交互更新（2026-11-10）

PO 与入库两个 Spend Cube 均将大类置于小类之前，表头支持数值／中文拼音升降序；点击小类先展示供应商金额排名与份额，再进入全部物料。物料直接列出供应商名称及金额份额；供应商类型与全部小类供货金额占比分列。物料表不重复展示未识别品牌状态标签。

展开明细为全屏，物料表和单物料详情新增2026年1—9月含税加权单价与采购单位。月单价为同料号、同月含税金额合计除以数量合计；无记录、净数量非正或已知单位冲突时留空。PO维持原有两个期间，与2026年月列取交集；来源截至2026年8月，9月为空。PO单位直接取U栏；入库源表无单位，沿用已核验的对应PO匹配结果，*表示仅部分入库有单位依据、供参考，无可靠依据时留空。
