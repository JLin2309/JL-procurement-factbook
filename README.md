# 嘉利采购 Fact Book

静态、可离线使用且可继续修改源码的采购分析网页，统计期为 **2026年1—9月**。

直接打开 `index.html` 即可使用，无需安装依赖或启动服务器。CSS、脚本、数据和参考图片均包含在该文件中。

- 采购树状图：12大类、29小类，展示金额、SKU与供应商数量；大类占比以总采购额为分母，小类占比以所属大类采购额为分母。
- 小类 Fact Book：覆盖全部20,743个SKU的产品分组、CR50、供应商CR10、长尾清单、报价构成、价格变动因素与采购方式。产品卡片直接展示类似产品参考图或标明范围的形态示意。
- 采购协同：共同供应商原始口径清单，以及按嘉利29小类的协同机会初判；统一分类、物料匹配及双方具体收益待确认。
- 专有名词检索：白话解释、产品用途与采购影响，支持搜索及正文术语跳转。
- 资料来源：资料链接、摘要、支持内容及适用边界。

当前展示版本已移除顶部编辑、导入及导出按钮；各类物料与共同供应商清单仍可下载。HTML源码可继续修改。网页不会自动修改GitHub仓库。

## 在线访问与更新

网站地址：https://jlin2309.github.io/JL-procurement-factbook/

GitHub Pages 使用 `main` 分支根目录发布，入口为 `index.html`。后续更新该文件并推送至 `main`，GitHub Pages会重新部署。

原始Excel及本地核验脚本不包含在部署目录内。当前版本包含29小类、205个产品组、73条术语与116条资料来源；统计口径与待核事项见网页说明。
