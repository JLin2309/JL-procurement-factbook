# 嘉利采购 Fact Book

静态、可离线使用的采购分析网页，统计期为 **2026年1—9月**。

直接打开 `index.html` 即可使用，无需安装依赖或启动服务器。CSS、脚本、数据和参考图片均包含在该文件中。

- 采购树状图：12大类、29小类，展示金额、SKU与供应商数量。
- 小类 Fact Book：覆盖全部20,743个SKU的产品分组、CR50、供应商CR10、长尾清单、报价构成与采购方式。
- 采购协同：共同供应商原始口径清单；统一分类、物料匹配和协同评级待确认。
- 资料来源：资料链接、摘要、支持内容及适用边界。

点击“编辑分析”可修改品类分析与来源说明。编辑只保留在当前网页会话中；请点击“下载当前 HTML”保存完整文件，或“导出数据”备份。网页不会自动修改 GitHub 仓库。

## 后续部署到 GitHub Pages

在确认发布后，将 `index.html`、`.nojekyll` 与本说明提交至仓库。仓库 Settings → Pages → Deploy from a branch，选择 `main` 分支与根目录 `/ (root)`。部署入口为 `index.html`。

此仓库准备版本尚未推送或发布。公开发布后，网页中包含的采购金额、料号与供应商信息也会公开。原始Excel及本地核验脚本不包含在本部署目录内。
