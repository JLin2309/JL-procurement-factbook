# 嘉利采购 Fact Book

静态、可离线使用且可继续修改源码的采购分析网页，统计期为 **2026年1—9月**。

使用新版 Chrome 或 Edge 直接打开 `index.html` 即可使用，无需安装依赖或启动服务器。CSS、脚本、数据和参考图片均包含在该文件中。

- 采购树状图：12大类、29小类，展示金额、SKU与供应商数量；大类占比以总采购额为分母，小类占比以所属大类采购额为分母。
- 小类 Fact Book：覆盖全部20,743个SKU的产品分组、CR50、供应商CR10及长尾清单。供应商数量可点开，查看按采购金额降序排列的完整清单、累计占比与前10家分界；继续点击供应商名称，可查看全部小类的入库数量、含税金额与SKU，再进入原始入库明细。29小类提供38个报价场景，每个场景逐项说明费用、变动原因和具体采购动作，采用简短完整句；计算方式放在可展开的计价参考中，并保留公开来源。无直接依据的成本占比不列示。
- 采购协同：共同供应商清单、按嘉利29小类的协同机会初判，以及108组相同／相似物料的1—9月含税加权单价比较，支持月度曲线与入库记录。
- Spend Cube：从品类、供应商和品牌三个维度查看采购。三个维度均支持采购小类筛选，表内SKU、供应商数和金额随所选小类更新；顶部全量概览保留总盘信息。覆盖725家供应商，其中263家供给多个小类；可查看供应商的品类前三大标签、分品类金额及具体物料。各维度顶部有全量概览，品牌概览另列已对应品牌的SKU与含税采购金额；未识别项支持按小类汇总并展开物料。品牌依据原始品名识别并与官方产品资料核对，列出对应采购小类、主要产品和有来源的市场定位，未识别品牌置于清单最后；品牌详情新增供应商总览，列示各供应商SKU数量及含税金额；供应商数量份额按单个物料计算，不跨料号加总。
- 专有名词检索：白话解释、产品用途与采购影响，支持搜索及正文术语跳转，覆盖报价拆解中的工艺、计价与性能用语。
- 资料来源：资料链接、摘要、支持内容及适用边界。

当前展示版本已移除顶部编辑、导入及导出按钮；各类物料与共同供应商清单仍可下载。HTML源码可继续修改。网页不会自动修改GitHub仓库。

## 在线访问与更新

网站地址：https://jlin2309.github.io/JL-procurement-factbook/

GitHub Pages 使用 `main` 分支根目录发布，入口为 `index.html`。后续更新该文件并推送至 `main`，GitHub Pages会重新部署。

原始Excel及本地核验脚本不包含在部署目录内。当前版本包含29小类、205个产品组、154条采购与工艺术语；产品卡片直接展示参考图或标明范围的形态示意，并附2—3句有外部依据的白话简介及来源跳转。

报价拆解用于询价核对，不代表嘉利实际成本。公开资料中的比例另列原分母与适用范围；缺少可靠证据的成本占比已移除。未能核实的品牌保留为“未识别／待核对”，不会依据供应商名称或通用型号强行归属。

供应商原始明细覆盖2026年1—9月517,569条入库记录，按725家供应商压缩内嵌，可离线按月份、小类、物料编码或名称筛选及下载。数量取原表J列、含税金额取S列；不同物料数量不代表统一计量单位。明细的23,604个SKU×供应商组合已与原有汇总逐一核对。

Chilisin（奇力新）已确认为独立品牌：5个SKU，含税采购金额201,433元，均属晶振磁珠。品牌说明附官方产品资料与国巨年报；四个ABPY型号已核对规格，旧PBY型号保留型号待核对说明。全量已对应品牌现为41个、1,616个SKU、72,974,910元。
